# 富文本编辑器方案（CultureEditor · 自研封装）

> **本次改造**：删除 135 编辑器 / 秀米 的全部集成（页面按钮、`third-editor.js`、`vendor/xiumi/`），
> 重新设计正文编辑器；富文本图片与视频改存项目根新目录 `upload/media/`。

## 一、结论

- 编辑器 = **本地 Quill 2 内核 + 自研包装层 `CultureEditor`**：无需 npm 构建，后台 jQuery/Thymeleaf 页面直接引用；
- 工具栏全部中文提示、分组重排，新增**视频上传、表格、分割线、HTML 源码、全屏、字数统计**；
- 正文媒体（图片/视频）落盘到 `upload/media/{image,video}/yyyyMM/`，URL 前缀 `/upload/media/**`；
- **不再依赖任何第三方排版站点**，没有 135 / 秀米的按钮、iframe、剪贴板导入逻辑。

## 三、功能对照

| 分组 | 功能 |
|---|---|
| 段落 | 标题 1/2/3、正文、字号（小/正常/大/特大）、对齐（左/中/右/两端） |
| 字符 | 加粗、斜体、下划线、删除线、字体颜色、背景颜色 |
| 列表 | 有序列表、无序列表、减少缩进、增加缩进 |
| 块 | 引用、代码块、分割线 |
| 插入 | 链接、图片（多选上传）、视频（本地上传 / 链接）、表格 |
| 表格 | 插入 3×3、自定义行列、上方/下方插入行、左侧/右侧插入列、删除行/列/表格 |
| 工具 | 撤销、重做、清除格式、字数统计、HTML 源码、全屏编辑 |

- **图片**：工具栏按钮可多选上传，也支持 `Ctrl+V` 粘贴、拖拽上传；插入到光标位置；
- **视频**：本地视频（mp4/webm/ogg/ogv/mov/m4v）用自定义 blot 输出 `<video controls>`，
  外链（B 站等播放页）用 Quill 内置 `iframe` 嵌入；
- **源码模式**：`</>` 按钮切换 textarea，可直接粘贴/编辑 HTML，切回可视化即时生效；
- **全屏**：`⛶` 进入全屏编辑，`Esc` 退出；
- **字数**：工具栏右侧实时显示非空白字符数。

## 四、后端接口

| 接口 | 入参 | 落盘位置 | 返回 |
|---|---|---|---|
| `POST /file/uploadEditorImage` | `file`（jpg/jpeg/png/gif/webp/bmp，默认 ≤10MB） | `upload/media/image/yyyyMM/uuid.ext` | `{errno:0,url:"/upload/media/image/yyyyMM/xxx.jpg"}` |
| `POST /file/uploadEditorVideo` | `file`（mp4/webm/ogg/ogv/mov/m4v，默认 ≤200MB） | `upload/media/video/yyyyMM/uuid.ext` | `{errno:0,url:"/upload/media/video/yyyyMM/xxx.mp4"}` |

失败统一返回 `{errno:1,message:"..."}`；上传请求会自动携带后台 Token（`Authorization: Bearer <culture_admin_token>`），
即使 Session 过期也能上传。

### 4.1 上传体积上限（易踩坑）

Spring Boot **默认 `max-file-size=1MB`、`max-request-size=10MB`**，若不配置，任何真实照片（几 MB）与视频
都会在进入 Controller 之前抛 `MaxUploadSizeExceededException` → 前端只看到「上传失败」。本项目已在
`application.yml` 放开，并加了全局 `UploadExceptionHandler` 把超限转成 413 + JSON 提示：

```yaml
server:
  tomcat:
    max-http-form-post-size: 20MB   # 富文本很长时随表单提交也不会被截断
    max-swallow-size: 220MB
spring:
  servlet:
    multipart:
      max-file-size: 200MB          # 单文件
      max-request-size: 220MB       # 单请求
      file-size-threshold: 2MB
```

业务层再各自校验：图片 ≤ `editor.upload.max-image-mb`(10MB)、视频 ≤ `editor.upload.max-video-mb`(200MB)，
超限返回 `{errno:1,message:"文件超过上限 …"}`。

## 五、目录与配置

```
upload/                       # 项目根新建目录
└── media/
    ├── image/yyyyMM/         # 正文图片
    └── video/yyyyMM/         # 正文视频
```

```yaml
editor:
  upload:
    path: ${EDITOR_UPLOAD_PATH:D:/me/AI/culture/upload/media}   # 部署时改为 /www/wwwroot/culture/upload/media
    max-image-mb: 10
    max-video-mb: 200
```

- 该目录由 `MyPicConfig` 映射为 `/upload/media/**`，并在 `WebSecurityConfig` 中放行（公开可访问）；
- 正文 HTML 保存的是**相对 URL**，数据库迁移时只要同步迁移 `upload/media/` 即可；
- 与头像（`upload/avatar`）、文化封面（`upload/culture`）完全隔离，便于单独备份。

## 六、页面接入方式

```html
<link rel="stylesheet" th:href="@{/static/admin/js/vendor/quill/quill.snow.css}">
<link rel="stylesheet" th:href="@{/static/admin/css/culture-editor.css}">
...
<div id="info-editor"></div>
<script th:src="@{/static/admin/js/vendor/quill/quill.js}"></script>
<script th:src="@{/static/admin/js/culture-editor.js}"></script>
<script>
  var editor = CultureEditor.create('#info-editor', { name: 'infoEditor', height: 420 });
  editor.setHTML('<p>已有内容</p>');
  // 保存前同步到隐藏域
  document.querySelector('#recipient-info').value = editor.getHTML();
</script>
```

API：`getHTML() / setHTML(html) / getText() / count() / isEmpty() / clear() / focus()`、
`insertImage(url) / insertVideo(url) / uploadImages(files) / uploadVideos(files)`、
`toggleSource() / toggleFullscreen() / busy(on,text) / on(event,fn)`；`CultureEditor.get(name)` 取实例。

## 七、历史方案（已废弃）

早期实现用 `third-editor.js` 把 135 编辑器 / 秀米 用 iframe + 剪贴板导入的方式嵌进来（免 appkey 路线），
并在 Quill 中注册 `AppPanelEmbed` 整段 HTML 嵌入块。该方案需要用户跳转到第三方站点排版、依赖剪贴板权限、
且第三方 HTML 会带入大量内联样式，已在本版本中**整体删除**；如后续确实需要第三方排版能力，
建议改为「粘贴 HTML 后本地清洗（白名单过滤内联样式）」而不是重新引入 iframe 集成。
